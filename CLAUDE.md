# MP Mercado

## Flujo de trabajo con git

- Después de cada cambio que se haga en el proyecto, hacer commit y push a `origin main` automáticamente, sin preguntar.
- Mensajes de commit en español, con el prefijo `propuesta:` (ej: `propuesta: empanaditas de pollo y hongos a $36.000`).
- No agregar archivos sueltos que no formen parte del cambio pedido (ej: imágenes sin trackear) salvo que se pida.
